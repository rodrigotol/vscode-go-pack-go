# Support

For bugs and feature requests, open an issue at <https://github.com/rodrigotol/vscode-go-pack-go/issues>.

Please include:

- VS Code version and operating system;
- Go Pack Go and Go extension versions;
- Go and Delve versions when the issue involves running or debugging;
- a minimal Go file or repository that reproduces the behavior;
- the expected and actual results; and
- relevant output from **Go Pack Go: Run Go Main** with `goPackGo.enableDebugLogs` enabled, if applicable.

Do not include credentials, private source code, or other sensitive information in a public issue.
